# Annotation v1

Parent: none (first version).

## What this version represents

The first reviewed labelling of the VBCT min15_area95 selected-resolution
clusters: 127 source clusters across eight samples mapped to eight broad cell
types (tier 1 only). It is the labelling behind the October-November 2026
preliminary results, including the HCA poster figures.

## Changes and reasons

- Migrated on 2026-11-22 from
  `config/08_cell_type_annotation/vbct/min15_area95_selected_resolutions_cell_type_mapping.csv`
  and `shared_cell_type_palette.json` (column `cell_type` renamed to
  `cell_type_tier_1`; palette restructured into a `tier_1` section). Labels and
  colours are unchanged.
- Label spelling was normalised to the canonical broad types when the mapping was
  first built (2026-10-25), e.g. `Melanoma`, `Melanoma cells` -> `Melanoma cell`.
