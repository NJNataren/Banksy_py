## Recommended Combined Mask Pattern

Script 05 should create and store:

```text
qc_keep_for_reclustering
qc_filter_status
```

Example logic:

```python
keep_mask = pd.Series(True, index=adata.obs_names)

for col in pass_filters:
    keep_mask &= adata.obs[col].astype(bool)

for col in fail_filters:
    keep_mask &= ~adata.obs[col].astype(bool)

adata.obs["qc_keep_for_reclustering"] = keep_mask
adata.obs["qc_filter_status"] = keep_mask.map({True: "Pass", False: "Fail"}).astype("category")
adata_filtered = adata[keep_mask].copy()
```

Script 05 should validate that all configured filter columns exist and have non-null values before filtering.

## Immediate Next QC Metric Before Script 05

Add a script 01 metric for cells with transcripts from two or more distinct negative-control probes.

Desired `.obs` columns:

```text
n_neg_control_probes_detected
negative_control_probe_ge2
negative_control_probe_ge2_cat
```

Definition:

```text
negative_control_probe_ge2 = n_neg_control_probes_detected >= 2
```

Important distinction:

```text
control_probe_counts alone is not enough.
```

This metric needs transcript-level `neg_tx` / `neg_tx_assigned` data so it counts distinct `NegControlProbe_*` feature identities per cell. A cell with many counts from one probe is different from a cell with counts from two or more distinct probes.

Suggested implementation sketch in script 01 after `neg_tx_assigned` exists:

```python
neg_probe_diversity = (
    neg_tx_assigned
    .groupby("cell_id")["feature_name"]
    .nunique()
    .rename("n_neg_control_probes_detected")
)

adata.obs["n_neg_control_probes_detected"] = (
    adata.obs_names.astype(str)
    .map(neg_probe_diversity)
    .fillna(0)
    .astype(int)
)

adata.obs["negative_control_probe_ge2"] = (
    adata.obs["n_neg_control_probes_detected"] >= 2
)

adata.obs["negative_control_probe_ge2_cat"] = (
    adata.obs["negative_control_probe_ge2"]
    .map({True: "Fail", False: "Pass"})
    .astype("category")
)
```

Recommended plots/tables:

```text
tissue_spatial_scatter_negative_control_probe_ge2_cat_<sample>.png
negative_control_probe_diversity_summary.csv
optional UMAP QC plots across resolutions
```

This should be reviewed before deciding whether `negative_control_probe_ge2` is an actual filtering criterion or inspection-only.
